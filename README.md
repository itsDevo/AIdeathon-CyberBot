# AIdeathon Cybersecurity Chatbot (LangChain + Groq + PyQt5)

This project is a cybersecurity-focused chatbot developed as a group project. It is designed to improve user awareness and understanding of cybersecurity concepts through an interactive quiz-based experience.

The chatbot generates a cybersecurity quiz, collects the user’s answers, and evaluates them at the end by providing structured feedback and suggestions for improvement.

### Project Overview

The chatbot follows a simple learning workflow:

1. The system generates a set of cybersecurity quiz questions.
2. The user answers each question through the graphical interface.
3. Once the quiz is completed, the chatbot evaluates the responses.
4. The chatbot provides feedback, highlights incorrect answers, and suggests areas for improvement.

### Key Features

- Automatically generates cybersecurity quiz questions using an LLM.
- Interactive question-and-answer flow for the user.
- Final evaluation of answers with performance feedback.
- Desktop GUI interface implemented using PyQt5.
- Structured chatbot logic using LangChain.

### Technologies Used

- Python
- LangChain
- Groq (LLM inference)
- PyQt5 (GUI)

### Goal of the Project

The main goal of this project is to provide an interactive learning tool that helps users strengthen their cybersecurity knowledge through quizzes and AI-generated feedback.
